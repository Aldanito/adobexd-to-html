# Share this after the repo is public

**Pitch:** Open Adobe XD `.xd` files as HTML without installing Adobe XD. One page per artboard.

**Why now:** XD is wound down; archives still need to be opened.

**Demo:** `node ./bin/xd-to-html.js ./examples/dashboard.xd -o ./out` then open `out/index.html`. Live export: GitHub Pages (Settings → Pages → GitHub Actions).

**Do not claim:** production websites, Figma replacement, or pixel-perfect type on every machine.

**Places:** Adobe XD / “XD sunset” threads, Designer News, Reddit r/AdobeXD, indie hacker “show HN” with a GIF of export → click.

**GIF:** record exporting `examples/dashboard.xd` and opening the Overview / dashboard artboard in the browser.
