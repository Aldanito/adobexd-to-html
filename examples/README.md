# examples

- `dashboard.xd` — public UI kit used for GitHub Pages and the README screenshot (sign-in, dashboard screens).
- `sample.xd` — tiny CI fixture (Home / About, tap between them). Regenerated with `npm run sample:xd`.
- `build-sample-xd.js` — sample builder.
- `demo/` — local export (`npm test` uses sample; Pages uses dashboard); gitignored. Includes `react/` JSX.
